# ريّــد | REID — Link in Bio

صفحة روابط واحدة لشركة **ريّــد (REID)**، تجمع لينكدإن والواتساب والبريد الإلكتروني وانستقرام والموقع الإلكتروني
في مكان واحد، **بالعربي والإنجليزي**. الصفحة مبنية بـ HTML/CSS/JS فقط — بدون أي مكتبات أو خطوات بناء.

## تعديل الروابط

كل ما تحتاجه موجود في ملف واحد: **`config.js`**.

```js
window.REID_CONFIG = {
  name:    { ar: 'ريّـــد', en: 'REID' },
  tagline: { ar: 'نبتكر مشاريع، ونصنع مبتكرين', en: 'Building projects. Making innovators' },
  links: {
    linkedin:  'https://www.linkedin.com/company/reidpro/',
    whatsapp:  '96897308003',    // بالصيغة الدولية، بدون + وبدون مسافات
    email:     'reid.contact.us@gmail.com',
    instagram: 'reid.pro_',      // اسم المستخدم بدون @
    website:   'https://reidpro.com/'
  },
  whatsappMessage: {
    ar: 'السلام عليكم، أود الاستفسار عن خدمات ريّد.',
    en: 'Hello, I would like to know more about REID’s services.'
  },
  defaultLang: 'ar'   // 'ar' أو 'en' أو 'auto' (حسب لغة المتصفح)
};
```

- أي رابط تتركه فارغًا `''` يختفي زره تلقائيًا من الصفحة.
- زر الواتساب يفتح المحادثة مباشرة مع رسالة جاهزة، ولكل لغة رسالتها.
- زرّا الواتساب والبريد فيهما زر نسخ سريع بجانبهما.

## اللغتان

في أعلى البطاقة زر تبديل بين **العربية** و**English**:

- يقلب اتجاه الصفحة كاملًا (RTL ↔ LTR) ويغيّر كل النصوص وعنوان الصفحة.
- يحفظ اختيار الزائر في المتصفح، فيفتح الصفحة بنفس لغته في المرة القادمة.
- يضيف `?lang=ar` أو `?lang=en` للرابط، فتقدر تشارك الصفحة بلغة محدّدة مباشرة.
- نصوص الواجهة (أسماء الأزرار، حقوق النشر، رسائل النسخ) في جدول `STRINGS` أعلى `app.js`.

الشعار يبقى بالعربي في اللغتين لأنه شعار الشركة الرسمي. إذا عندكم نسخة لاتينية منه
أضِفها في `assets/` واستبدل `logo-wordmark.svg` عند اللغة الإنجليزية.

## التشغيل محليًا

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر

الصفحة ملفات ثابتة فقط، لذا تعمل مباشرة على أي استضافة:

- **GitHub Pages** — من إعدادات المستودع: Settings → Pages → اختر الفرع ثم `/ (root)`.
- **Netlify / Vercel / Cloudflare Pages** — اسحب المجلد أو اربطه بالمستودع، بدون أمر بناء.

## الملفات

```
index.html                  هيكل الصفحة
styles.css                  التنسيقات وألوان الهوية
config.js                   ← الروابط والبيانات (عدّل هنا)
app.js                      يبني الأزرار من config.js
_og.html                    مصدر صورة المشاركة (لإعادة توليد assets/og.jpg عند تغيير الشعار أو الوصف)
assets/
  logo-mark.svg             الرمز (الأعمدة)
  logo-wordmark.svg         الاسم المكتوب
  logo-lockup.svg           الشعار الكامل (رمز + اسم)
  favicon.svg               أيقونة المتصفح
  apple-touch-icon.png      أيقونة الشاشة الرئيسية على iOS
  og.jpg                    صورة المعاينة عند مشاركة الرابط
```
